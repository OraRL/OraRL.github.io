# OraRL project page

Static project website for **Annotations as Rollouts: Efficient and Scalable
Reinforcement Learning for Video MLLMs**.

## Update links

Resource URLs are defined once at the top of `script.js`. Add the final arXiv
URL to `paper` after the identifier is assigned.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Deploy

Push the contents of this folder to the root of the `OraRL/orarl.github.io`
repository and enable GitHub Pages from the default branch.
